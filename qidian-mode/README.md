# โหมด Qidian (网文模式)

คลังกฎโครงสร้างนิยายเว็บจีน สำหรับบังคับจังหวะการเขียนของ Tale Engine
ให้เขียนแบบเว็บโนเวลจีนจริงๆ แทนที่จะเป็น "AI เล่าเรื่องไปเรื่อย"

---

## อยู่ในนี้อะไรบ้าง

| ส่วน | เนื้อหา |
|---|---|
| `CADENCE` | ค่าสถิติเชิงรูปทรง — สัดส่วนบทสนทนา ความยาวย่อหน้า ตำแหน่งเบ็ด จำนวนชื่อเฉพาะใหม่ต่อตอน |
| `GOLDEN3` | กฎ 黄金三章 — สามตอนแรกต้องทำอะไรให้ครบ |
| `GOLDFINGER` | ประเภทของโกลด์ฟิงเกอร์ 5 สาย + กฎการตั้งข้อจำกัดไม่ให้เรื่องพัง |
| `SHUANG` | จุดสะใจ (爽点) 8 ชนิด — ระบบหมุนเวียนให้อัตโนมัติตามเลขตอน |
| `HOOKS` | คลิฟแฮงเกอร์ 6 ชนิด — หมุนเวียนเช่นกัน ห้ามซ้ำติดกัน |
| `ARC` | โครงอาร์ก 6 ขั้น + จังหวะสามตอน + กฎการยกเพดานศัตรู |
| `HUIMU` | ขนบ 章回体 — ชื่อตอนแบบโคลงคู่ และวิธีบรรยายแบบจีน |
| `ANTI` | ข้อห้าม 8 ข้อ กลั่นจากคำบ่นของคนอ่านจริง |

---

## มันทำงานยังไง

**1. ตอนสร้างคำสั่ง (ก่อนเรียก Gemini)**
`QIDIAN.rules(state)` ประกอบกฎเข้า system prompt โดย
- หมุนชนิดจุดสะใจและชนิดเบ็ดตาม "เลขตอนปัจจุบัน" → ไม่ซ้ำแบบกลไก
- ถ้ายังอยู่ตอนที่ 1–3 จะสลับไปใช้กฎ 黄金三章 แทนกฎอาร์ก

**2. ตอนตรวจผล (หลัง Gemini ตอบ)**
`QIDIAN.audit(text, state)` วัดตอนที่เพิ่งเขียนในเครื่อง ไม่เสียโควตา API:
สัดส่วนบทสนทนา · ย่อหน้ายาวเกิน · ลืมชื่อตอน · ปิดตอนด้วยการถามผู้เล่น · ขั้นพลังไม่ขยับ

**3. ป้อนกลับ**
ผลตรวจถูกเก็บใน `state.qidianNotes` แล้วยัดกลับเข้า prompt ของตอนถัดไปในหัวข้อ
*"ผลตรวจตอนที่แล้ว — ต้องแก้ให้ได้ในตอนนี้"* → คุณภาพไต่ขึ้นเองโดยไม่ต้องสั่ง

## แหล่งที่มา และขอบเขตทางลิขสิทธิ์

ไฟล์นี้บรรจุ **กฎ จังหวะ โครงสร้าง และค่าสถิติ** เท่านั้น
ไม่มีตัวบท ประโยค หรือคำแปลของนักเขียนคนใดอยู่ในนี้เลย — ไอเดีย ขนบ และโครงเรื่องไม่ใช่สิ่งที่ลิขสิทธิ์คุ้มครอง

กลั่นมาจาก
- คู่มือการเขียนของแพลตฟอร์มจีนและบทความสอนเขียนสาธารณะ (黄金三章, การออกแบบ 金手指, ความต่างของจังหวะระหว่างแพลตฟอร์มฟรี/เสียเงิน)
- บทวิเคราะห์เชิงวิชาการเรื่อง 系统流 ในวรรณกรรมเครือข่าย
- รีวิวและคำวิจารณ์ของคนอ่านฝั่งอังกฤษ (ที่มาของหมวด `ANTI`)
- ขนบ 章回体 ของนิยายจีนคลาสสิกที่หมดลิขสิทธิ์แล้ว (รูปแบบ 回目, การบรรยายฉากสู้ทีละกระบวน)
- แนวทางความยาวตอนและตำแหน่งเบ็ดของนิยายแบบตีพิมพ์เป็นตอน

**สิ่งที่โหมดนี้ไม่ทำ:** ไม่ดึงเนื้อหาตอนจาก qidian.com หรือเว็บแปลใดๆ ไม่เก็บตัวบทของใคร
และไม่ผลิตงานแปลหรืองานดัดแปลงจากนิยายที่ยังมีลิขสิทธิ์

---

## แก้ค่าเอง

เปิด `qidian.js` แล้วแก้ค่าในหมวดที่ต้องการได้เลย ไม่ต้อง build
- อยากให้จังหวะสะใจถี่ขึ้น → ลด `CADENCE.shuangEveryChapters`
- ไม่ชอบชื่อตอนแบบโคลงคู่ → ลบบรรทัด `"◇ ..."` ในฟังก์ชัน `rules()` และตัดเช็ก `hasTitle` ใน `audit()`
- อยากเพิ่มจุดสะใจชนิดใหม่ → เติมสตริงลงอาเรย์ `SHUANG` ระบบจะหมุนให้เอง
